# 스타의 댓글 모아보기 — 회차 기록

회차마다 한 블록. 상태는 4단계를 따로 적는다 — **앞 단계가 끝났다고 뒤 단계를 완료로 쓰지 않는다.**

- **머지**: main에 들어갔다
- **빌드**: 포털에서 빌드가 성공했다
- **반영(LIVE)**: 포털에서 페이지에 반영해 라이브가 됐다
- **팬 확인**: 라이브 팬 화면(또는 어드민 콘솔)에서 실제로 눈으로 확인했다

표기: ✓ 확인함 · ✗ 실패 · ○ 해당 없음 · **미확인** 확인하지 못함(통과가 아님)
기록 원칙: 회차의 증거(커밋·빌드 ID·확인 방법)를 적고, 이전 회차의 결과를 지금 회차의 통과로 옮기지 않는다.
상세 diff는 git 기록을 본다 — 여기에는 판단에 쓴 사실만 적는다.

현재 라이브: 어드민 `0c3e068`(빌드 `#61468b`) · 유저 `ea7157d`(빌드 `#0c0fa2`), 자리 9곳(페이지 1 + 슬롯 8) LIVE — 2026-10-27 기준.

### R8 — 스타 칩 (스타 순서의 닉네임을 칩으로)
- 배경: 스타 목록 API가 400이라 댓글이 없는 스타(애뤼애나)가 칩에서 사라짐

- 머지 ✓ · 빌드 ✓ `#0c0fa2` · 반영 ✓ 9곳 · **팬 확인 미확인**
- 확인한 것: 로컬에서 `메리·애뤼애나·Gini` 순서 + 메리 숨김 → `전체 스타 / 애뤼애나 / Gini`
- 미확인: 라이브 설정의 "스타 순서"가 비어 있어서(누군가 10/27 18:11 저장) 라이브에서 애뤼애나가 뜨는지 못 봄. 스타 목록 API 400은 그대로.

### R7 — 이 스테이지에 있는 화면만 자리 목록에 (라운지·큐레이션)
- 증거: 어드민 `a3d9832`(PR #14) → `0c3e068`(PR #15), 빌드 `#61468b`
- 머지 ✓ · 빌드 ✓ · 반영 ✓ · 팬 확인 ✓(어드민 콘솔)
- 확인한 것: 라이브 콘솔에서 라운지 3곳 숨김 + 안내 문구, "그래도 보기" 토글, 큐레이션 자리는 큐레이션이 있어 남음
- 판단 근거(추정): 라운지 확인 API가 어드민에 없고, 라운지 홈 조회가 이 스테이지에서 400 → "라운지 없음"으로 봄. 라운지가 있는 스테이지에서의 응답은 미확인.
- 정정: 한때 "큐레이션이 없다"고 말했으나 틀렸다 — 어드민 API로 큐레이션 섹션(노출 중, 콘텐츠 3개)이 확인됨.
