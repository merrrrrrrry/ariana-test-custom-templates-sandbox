# 포털 배포 절차와 주의점

스타의 댓글 모아보기를 포털(b.stage kit)에서 빌드·반영·확인하는 방법. **인증 값(앱 키, 비밀번호, 토큰)은 이 문서와 저장소에 적지 않는다.**
키 값은 사용자가 포털 빌드 환경변수에 직접 입력하고, 로그인과 팬 사이트 비밀번호도 사용자가 직접 한다.

## 배포 순서 (머지 이후)

1. **조직 확인**: 포털은 처음에 조직 `비마이프렌즈`로 열린다. 왼쪽 메뉴의 조직 이름 버튼을 눌러 `test`로 바꾼다. 이 조직에 `ariana-test`가 있다.
2. **빌드**: 레포 상세 → 헤더 **빌드** → 확인 창 **빌드**. 빌드는 자동이 아니다. 약 60~80초 걸린다. 최신 커밋이 방금 머지한 커밋인지 먼저 본다("빌드 필요" 표시).
3. **반영**: 빌드가 끝나면 **최신 빌드 반영** → "빌드 결과 반영" 창.
   - 유저 레포: 이 작업과 무관한 페이지 4개(`/merry-test-hello`, `/star-feeds-random`, `/merry-star-feeds-popular`, `/merry-lucky-wheel`)는 **체크 해제**한다 → "9개 반영".
   - 어드민 레포: 대상은 `/star-comments-settings` 하나.
   - 이어서 뜨는 "게시 중인 페이지에 바로 반영됩니다" 창에서 **반영**. 이 순간 사이트에 바로 나간다.
4. **새 슬롯·페이지**를 처음 등록했다면 등록 뒤 페이지별로 **게시**해야 한다.
5. **확인**(아래).

## 확인 (상태 4단계 중 "팬 확인")

- **포털 상태**: 포털의 placements API(`/api/v1/organizations/test/stages/ariana-test/placements?surface=USER` 또는 `ADMIN`, 로그인한 포털 탭에서 호출)로 각 슬롯·페이지의 `status`와 `liveCommit`을 본다. 이 응답에는 다른 값이 섞일 수 있으니 필요한 필드만 읽는다.
- **팬 화면**: 팬 사이트 비밀번호를 통과한 뒤 독립 페이지, 콘텐츠 탭, 섹션 전체보기, 콘텐츠 상세(본문 아래·댓글 위)에서 위젯 위치를 본다. 운영자용으로 `?curate=1`을 붙이면 카드마다 "ID 복사" 버튼과 연결 점검 줄이 보인다.
- **어드민**: 콘솔 로그인 후 설정 화면에서 "마지막 수정", "어디에 보여줄까요" 목록, "연결 점검"을 본다.
- 설정을 바꾸면 팬 화면에는 약 10초 뒤 반영된다(팬 화면이 1분 단위 값으로 읽는다).

## 알려진 동작 (놀라지 않기)

- **"인증 값 1건 확인 필요"**: 어드민 빌드는 키가 `bsp_`가 아니라 `bsm_`로 시작해서 늘 뜨는 경고다. 알려진 오탐이라 반영을 진행해도 된다.
- **HTTP 503**: 배포 직후 설정 읽기가 잠깐 503일 수 있다. "다시 불러오기"로 풀린다.
- **HTTP 401**: 콘솔 로그인 세션이 만료된 것. 사용자가 다시 로그인한다.
- **페이지가 안 뜸/"불러오는 중"에서 멈춤**: 브라우저 패널이 숨겨져 있으면 렌더링이 매우 느리다. 패널을 보이게 하고 새 탭에서 다시 연다.
- **레포 목록이 비어 보임**: API 응답이 느려서일 수 있다. 몇 초 기다리거나 새 탭에서 다시 연다.
- **포털 첫 클릭**: 첫 클릭이 먹지 않는 경우가 있다. 실패했다고 결론내기 전에 한 번 더 누른다.
- **어드민 키**: MANAGEMENT 키(`bsm_`)의 허용 Origin에 `https://ariana-test.mysandstage.in`이 있어야 한다.
- **설정 JSON 키**: 점(`.`)이나 `$`가 있으면 저장소가 500. 설정 키는 점 없는 짧은 키를 쓴다.
- **어드민 API**: 어드민 `/svc/...` 호출은 콘솔 자체 토큰이 필요해서 쿠키만으로는 401이다. SDK는 `/gw` 경로에만 인증을 붙인다.

## 하지 않는 것

- 포털의 repos API 응답을 통째로 출력하지 않는다(빌드 환경변수 값이 들어 있다).
- 로그인·비밀번호·키 입력을 AI에게 맡기지 않는다.
- 사용자의 명시적 지시("머지해도 돼", "머지하고 배포해줘") 없이 머지하지 않는다. 지시에 말한 범위(머지만 / 머지+빌드+반영)까지만 진행하고, 말하지 않은 단계는 하지 않는다.
- 라이브 설정 값(스타 순서, 자리, 숨김 등)은 사용자가 값을 정해 주기 전에 저장하지 않는다.
- 포털·콘솔의 삭제(페이지 등록, 레포 연결)는 AI가 하지 않고 사용자가 직접 한다.
