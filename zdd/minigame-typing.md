# 가사 빨리 치기 (미니게임) — spec

팬 화면에 붙이는 짧은 미니게임. 화면의 문장을 그대로 따라 치면 입력 시간과 분당 타수가 나오고, 닉네임으로 **문장별 랭킹**에 오른다.
페이지 `src/pages/minigame-typing`(경로 `/minigame-typing`), 템플릿 이름 `ariana-test-minigame-typing`.
랭킹 서버: 뷰어 수와 같은 hosting 앱(`ariana-test-viewers-server`)의 `/api/typing/*` (그 레포 README "가사 빨리 치기 랭킹" 참고).

## 규칙
- 한 판 = 문장 1개(약 5~10초). 첫 글자를 치는 순간 시간이 시작되고, 입력이 문장과 **정확히 같아지면** 끝난다.
- 타수(분당) = 문장의 자모 수 ÷ 걸린 시간(분). 한글은 자모로 풀어 센다(`keystrokeCount`). 겹모음·겹받침은 자모 1개로 세어 실제 키 입력보다 조금 적다.
- 치는 동안: 맞은 글자는 진하게, 틀린 글자는 빨갛게, 칠 차례 글자는 깜박이는 밑줄. 한글을 조합하는 중인 글자는 틀린 것으로 치지 않는다.
- 화면에 실시간 타수·입력 시간·진행 막대·내 최고 타수. Enter = 다음 문장, Esc = 같은 문장 다시. 붙여넣기·끌어놓기 차단.
- 사람이 낼 수 없는 속도(분당 1000타 초과, `MAX_PLAUSIBLE_CPM`)는 이 기기의 기록에도, 서버에도 올리지 않는다.

## 랭킹 (닉네임만, 로그인 없음)
- **문장마다 따로** 순위를 매긴다(문장 길이·난이도가 달라 한 줄로 비교하지 않는다). 문장 id는 서버가 문장 글자의 해시로 정한다.
- 화면에서 "도전할 문장"을 고르거나 무작위로 도전하고, 아래 "문장별 랭킹"에서 문장을 골라 그 문장의 상위 10명을 본다. 다른 문장의 랭킹에서 "이 문장에 도전하기"로 바로 넘어갈 수 있다.
- **문장과 시간은 서버가 정하고 잰다.** 화면은 "첫 글자를 쳤다"(`begin`)와 다 친 글자·닉네임(`finish`)만 보낸다. 서버가 보여 주는 타수·시간·순위가 화면의 최종 값이다.
- 닉네임 2~10자(한글·영문·숫자·공백·`_`·`-`). 이 기기에 기억한다. 닉네임마다 문장별 최고 기록 하나. 닉네임을 정하지 않았으면 기록을 올리지 않고, 정한 뒤 "랭킹에 올리기"로 올릴 수 있다.
- 서버에 연결하지 못하면 이 기기의 연습 문장으로 진행한다(랭킹은 올라가지 않고, 최고 기록은 이 기기에만 저장 — `localStorage` `ariana-test-typing-best`).
- **한계**: 서버는 사람이 쳤는지 프로그램이 쳤는지 알 수 없다. 닉네임은 본인 확인이 아니다. **랭킹에 보상을 걸지 않는다.**

## 문장
- 서버 `src/typingPhrases.js`가 정본이다. 화면의 `src/shared/typingPhrases.ts`는 서버에 연결하지 못할 때 쓰는 연습용 사본이다.
- 지금은 새로 지은 응원 문장이다(실제 노래 가사 아님). 실제 가사를 쓰려면 저작권 이용 허락을 먼저 확인하고, 허락받은 문장만 넣는다. 문장을 한 글자라도 고치면 그 문장의 랭킹은 비어서 다시 시작한다.

## 테스트·확인
- `tests/typing.test.ts`: 타수 계산, 완료 판정, 글자별 상태, 문장 고르기, 사람이 낼 수 있는 속도, 저장값 검증, 문장 목록.
- `tests/typingApi.test.ts`: 서버 응답 모양 검사, 오류 문구, 요청 경로·본문(화면이 시간·타수를 보내지 않음), 다른 문장의 순위가 섞이면 거부.
- 서버(`ariana-test-viewers-server`) `npm test`: 라운드·시간 측정·거부 규칙·문장별 순위 분리·닉네임 규칙.
- 로컬 확인(서버 개발용 실행 + 미리보기)에서 직접 본 것: 서버가 잰 시간·타수·"이 문장 N위", 문장별 랭킹 분리와 문장 바꿔 보기, 도전하기, 연결 실패 시 연습 판, 속도 초과 입력 거부 문구.
- **미확인**: 한글 조합 입력(IME)으로 실제 타이핑할 때의 모양, 실제 Postgres에서의 동작, hosting 배포·라이브 팬 화면.
