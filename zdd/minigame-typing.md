# 가사 빨리 치기 (미니게임) — spec

팬 화면에 붙이는 짧은 미니게임. 화면의 문장을 그대로 따라 치면 입력 시간과 분당 타수가 나온다.
페이지 `src/pages/minigame-typing`(경로 `/minigame-typing`), 템플릿 이름 `ariana-test-minigame-typing`.

## 규칙
- 한 판 = 문장 1개(약 5~10초). 첫 글자를 치는 순간 시간이 시작되고, 입력이 문장과 **정확히 같아지면** 끝난다.
- 타수(분당) = 문장의 자모 수 ÷ 걸린 시간(분). 한글은 자모로 풀어 센다(`keystrokeCount`). 겹모음·겹받침은 자모 1개로 세어 실제 키 입력보다 조금 적다.
- 치는 동안: 맞은 글자는 진하게, 틀린 글자는 빨갛게, 칠 차례 글자는 깜박이는 밑줄. 한글을 조합하는 중인 글자는 틀린 것으로 치지 않는다.
- 화면에 실시간 타수·입력 시간·진행 막대·내 최고 타수. Enter = 다음 문장, Esc = 이 문장 다시.
- 붙여넣기·끌어놓기는 막는다.

## 기록
- 최고 타수는 이 기기(`localStorage` `ariana-test-typing-best`)에만 저장한다. 서버로 보내지 않는다. 저장이 막히면 이번 방문 동안만 유지.
- 서버 랭킹은 **아직 없다.** 방향(서버가 문장·시간을 재고, 닉네임+기기 ID로 구분)은 정해지는 중이며, 이 문서에 반영한 뒤 구현한다.

## 문장
- `src/shared/typingPhrases.ts`. 지금은 새로 지은 응원 문장이다(실제 노래 가사 아님). 실제 가사를 쓰려면 저작권 이용 허락을 먼저 확인하고, 허락받은 문장만 넣는다.

## 테스트·확인
- `tests/typing.test.ts`: 타수 계산, 완료 판정, 글자별 상태, 문장 고르기, 저장값 검증, 문장 목록 모양.
- 화면(로컬 미리보기): 데스크톱·모바일 폭에서 따라가기·타수·시간·완료 화면·Enter 다음 문장을 직접 확인함. 한글 **조합 입력(IME) 상태의 실제 타이핑**은 자동 입력으로 흉내 내지 못해 **미확인**.
